Pre-request Script (JavaScript)

Runs before sending the request. You can access/set variables using the pm sandbox (e.g. pm.environment.set("key", "val")).

Tests Script (JavaScript)

Runs after response is received. Write tests using pm.test() and assertions with pm.expect().

Capture variables from the response

After every send, values are read from the JSON response and saved as variables (into the active environment, or globals if none is selected). Example: path data.token → variable token. Use status to capture the status code.

Tests

Checks that run after every send. Left column: status, body-contains, or a JSON path like data.user.id. Right column: expected value (leave empty to only check the path exists).
